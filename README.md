# כתבי יונתן יהודה ז״ל

אתר לזכרו של **יונתן יהודה ינקלוביץ ז״ל** — כתבים, שירים והקלטות,
לקריאה, להדפסה ולהורדה.

* לידה: כ״ז אייר תש״ס · 1 ביוני 2000
* פטירה: כ״ו אב תשע״ח · 7 באוגוסט 2018

ליד כל כתב, שיר והקלטה מופיע התאריך שבו נוצר — **עברי ולועזי** — ו**גילו של יונתן**
באותו יום. התאריכים נלקחים מתוך המידע הפנימי של קובצי ה-Word עצמם
(`dcterms:created`), כלומר מהתאריך שבו יונתן באמת יצר את הקובץ.

---

## איך מוסיפים תוכן חדש

התוכן מתעדכן לבד. אין צורך לגעת בקוד — רק לשים קבצים בתיקייה הנכונה ולהריץ בנייה.

| מה מוסיפים | לאיזו תיקייה | סוגי קבצים |
|---|---|---|
| כתב חדש | `כתבים_גיבוי\` | `.docx` |
| שיר | `שירים\` | `.docx`, `.txt`, `.md`, `.pdf`, תמונה סרוקה |
| הקלטה | `מוסיקה\` או `הקלטות\` | `.mp3`, `.wav`, `.m4a`, `.amr`, `.ogg` |

אחר כך:

```powershell
python build\build.py
```

הבנייה יוצרת מחדש את התיקייה `docs\` — האתר המלא, כולל קובצי PDF לכל כתב
וקובץ ZIP עם הכול.

### מתן שם להקלטה

הקלטות ללא שם מקבלות אוטומטית "הקלטה 1", "הקלטה 2"… לפי סדר כרונולוגי.
כדי לתת שם והסבר, יוצרים לצד קובץ הקול קובץ טקסט באותו שם עם סיומת `.txt`:

```
מוסיקה\160731-004.mp3
מוסיקה\160731-004.mp3.txt
```

בקובץ הטקסט: **שורה ראשונה = הכותרת**, שאר השורות = הסבר קצר שיוצג מתחתיה.

### כותרת יפה לכתב חדש

אם רוצים כותרת אחרת משם הקובץ, כותרת משנה או שיוך לאוסף — מוסיפים ערך
במילון `DOCS` שבקובץ `build\config.py`. כתב שלא מופיע שם פשוט יקבל את שם הקובץ ככותרת.

## העלאה לאינטרנט

האתר מתפרסם ב-GitHub Pages מהתיקייה `docs\` שבענף `main`.
אחרי בנייה מחדש:

```powershell
git add -A
git commit -m "עדכון תוכן"
git push
```

תוך דקה-שתיים האתר המקוון מתעדכן.

## מבנה הפרויקט

```
YONATAN\
├─ build\              קוד הבנייה
│  ├─ build.py         הסקריפט הראשי
│  ├─ config.py        הגדרות האתר + כותרות המסמכים
│  ├─ docx_read.py     קורא קובצי Word
│  ├─ make_icon.py     מייצר את האייקונים
│  └─ assets\          CSS ואייקונים
├─ docs\               ← האתר הבנוי (זה מה שמתפרסם)
├─ כתבים_גיבוי\        מקורות ה-Word של הכתבים
├─ שירים\              שירים
├─ מוסיקה\             הקלטות מקוריות (לא נשמרות בגיט - גדולות מדי)
├─ assets\icon.ico     אייקון הפרויקט
└─ IMG_9166.JPG        התמונה של יונתן
```
